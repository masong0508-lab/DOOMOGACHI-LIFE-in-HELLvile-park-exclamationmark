# home_turn.txt - S2-11 (make -C gba test-home): the house's view turn on the game ROM. A turn used to
# recompose the room in one tick (106 ms of work, one 117 ms frame); now the new view is built over 2-3
# ticks in the hidden page while the shown page keeps the old one (gba/src/room.c, "a view turn built over
# several ticks"). Every window below is a turn (or turns) and must hold 30 fps with no frame over 34 ms;
# the one that asks for turns faster than a build (Photo mode, three in a row) draws the third in one go, so
# its worst frame is the old one. The pictures of the sliced turn against the one-go frame are test-home's
# room-parity path 3 (home.txt, 1f). With `sync on` every tick is the same in any ROM.
wait 40
expect-log doomo: init
sync on 61
seed 1
scene HOME -1
wait 60
