# exorcism_fps.txt - the exorcism's drawn fps on the GBA, phase by phase, with floors (G2-EX,
# docs/EXORCISM_SPEED.md "G2-EX"): `make -C gba test-exorcism` (part of `make -C gba test`).
# The same ritual and the same windows as exorcism_profile.txt without its `profile` lines (which
# stop the emulated clock and so move what follows): Father Fuzz's practice ritual on the plush
# dummy (arg -1), seed 1 (it ends in a failure), then the same ritual with seed 2 (a cast out).
# `sync on 61` and the seeds make the ticks and the game state the same in any ROM, so the
# `vhash-seq` frames of two ROMs built with `make PSLICE_DET=1` compare frame for frame
# (gba/tools/speedtable.py --compare A B: the exact check of a package that claims "no pixel changes").
# The floors sit about 2-3 fps under what G2-EX measured on 2026-11-15 (intro 29.8, tools 29.7, prayer
# 27.5, holy water 30.0, true name 24.0, verdict 30.0, result 29.7) and above the tip before it (23.7,
# 27.0, 19.5, 23.6, 20.0, 19.3, 19.6): a fall back fails. A cast out's result is drawn in full every tick
# (19.8; 19.7 before): its floor only catches a regression. Numbers belong to this script.
