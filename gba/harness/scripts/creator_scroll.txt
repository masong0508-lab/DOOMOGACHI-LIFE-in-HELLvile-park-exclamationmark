# creator_scroll.txt - the creator's speed gates on the GBA (CR9): `make -C gba test-creator`.
# The owner's target is a steady 30 drawn fps on every screen (DECISIONS "FPS TARGET"); the floors
# below are regression gates at about 85-90% of what this ROM measures today (docs/CREATOR.md
# "Speed" has the table and the gap to 30: idle and the grid at rest reach 30, rows 26.8, a value
# held 19.8, the species grid scrolled 16.5). Numbers belong to this script (tick-exact: sync on,
# seed 1).
#
#   idle        a new Hillvile citizen on the Species & Body tab, nothing pressed
#   grid idle   the species grid open (A on Species), the cursor resting
#   grid scroll RIGHT held in the species grid (each species is tried on: a new figure every move)
#   rows        DOWN held through the Outfit tab's rows (the list redraws, no new look)
#   value step  RIGHT held on the Outfit preset row's neighbour, Top (a new look every few ticks)
