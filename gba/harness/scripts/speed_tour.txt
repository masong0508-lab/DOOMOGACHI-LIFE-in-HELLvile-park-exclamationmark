# speed_tour.txt - the GBA speed tour (G1, docs/GBA.md "Speed pass 4"):
# every target scene of the game ROM in turn, `make -C gba test-speed`.
#
# Each scene settles (wait 200), is measured over 130 logic ticks
# (fps start .. expect-fps), shot, and then the frames of the next 30
# ticks are hashed (vhash-seq: the emulator's output frame, so it holds in
# any display mode; the ROM draws every one of those ticks).
# gba/tools/speedtable.py turns the log into the table; --compare (or
# `make -C gba test-speed SPEED_BASE=LOG`) matches two ROMs' frames tick by
# tick.
#
# `sync on 61` makes every wait end on an exact logic tick, from absolute
# tick 61 on (the unsynced boot wait before it may end a tick late in one
# ROM and not in another), so keys and commands land on the same tick in
# any ROM however fast it draws, and `seed 1` before every scene pins
# plat_entropy() and the RNG: equal ticks are equal game states, and a
# scene's content does not depend on code timing.
#
# Every scene's ticks are absolute: a scene's numbers and frames depend on
# the tick it starts on and on the scenes before it (the town, the show
# generator). Adding or removing scenes or waits moves every later scene,
# so a parity base log must come from this same script (docs/GBA.md
# "Frame parity between ROMs": SPEED_SCRIPT, SPEED_GATES=0). Changing an
# expect-fps floor moves nothing.
#
# The expect-fps floors are regression gates at about 85% of the speed
# pass 4 baseline (the harness is deterministic: one ROM always gives the
# same numbers). A package that makes a scene faster raises its floor:
# G2 set the overworld visits to its gates (hahaland 24, hellvile and park
# 29, invaded 15; invaded must also keep its 30 logic ticks/s, which
# expect-fps cannot check: see the table) and the pause and story map to
# about 85% of what it measured. The pause panel's hold (PAUSE_SPEED.md,
# P2+P3) took it from 12.3 to 28.3 fps and its floor from 11 to 24. SP2
# (portrait slices, stand-ins, idle-time slices) raised the title to 25,
# the pause to 25, the map walk to 25, the concert to 12.5 and the town
# hall menu to 25 (85% of 29.9, 29.9, 30.0, 15.0 and 30.0).
# SP3 (ISLAND_SPEED.md I11, the toast band) took the island hub from 24.3
# to 29.9 fps and its floor from 6.3 to 25 (life_speed.txt's hub too).
# SP8 (Options "Combat detail", default Balanced: the resolution governor,
# two catch-up ticks after a 3D frame, the HUD badges as panels) took combat
# from 9.8 to 14.3-14.6 fps at 30 logic ticks/s and its floors 9 -> 12
# (make -C gba test-3d gates the game speed in every mode).
