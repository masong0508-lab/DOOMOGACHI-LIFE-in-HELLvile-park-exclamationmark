# exorcism_profile.txt - the exorcism's speed on the GBA, phase by phase (docs/EXORCISM_SPEED.md):
# `make -C gba profile-exorcism`. Father Fuzz's practice ritual on the plush dummy (arg -1), walked
# like core/tests/scripts/life_exorcism.txt: the intro under its dialogue, the tools menu, the
# prayer rhythm, the holy water, the true name, the verdict and the result.
#
# The reticle is held at the left edge (no hits), so the water phase ends when the flasks are
# thrown (6, or 9 with the holy water that the intro's last A ticks on), and its dialogue is closed
# with B (in the true-name phase only A picks): the phases do not depend on how many ticks
# `profile` takes.
# Every phase is measured with `fps` (drawn frames/s, logic ticks/s, average / worst CPU work of a
# drawn tick in ms) and sampled with `profile N` (the hottest functions). `sync on 61` and `seed 1`
# make the ticks and the game state the same in any ROM, so two ROMs' numbers and `vhash-seq`
# frames compare tick for tick. Numbers belong to this script.
