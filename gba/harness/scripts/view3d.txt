# view3d.txt - Options "Combat detail" in the shooter on the game ROM (SP8:
# G-C1, G-C2; docs/GBA.md "Combat detail"), `make -C gba test-3d` (part of
# `make test`). OPT_3D_FAST is option 63 (town.h): 0 Balanced (default),
# 1 Smooth, 2 Max detail.
#   - the row is on the Performance page (OPTPAGE_PERF = 7);
#   - in every mode the game keeps its 30 logic ticks a second
#     (expect-logic: catch-up ticks after a 3D frame, main.c), however slow
#     the view draws;
#   - Smooth draws the Vape Cellar at half resolution doubled by r3d_up2:
#     every 2x2 block of the view above the HUD is one colour;
#   - Balanced tries full then half resolution, and now uses an emergency
#     quarter-detail fallback when the half-resolution scene still misses
#     the 30 FPS frame budget. HUD is unchanged; 4x detail is intentional
#     in demanding rooms, not a new framebuffer. Max retains full/half.
#   - The Balanced thresholds below guard against losing the measured
#     >4 FPS gain (22.6 first-person, 22.2 third-person in mGBA).
#     Smooth/Max floors retain the older conservative thresholds.
# expect-logic is the 30 Hz game speed less 1.
