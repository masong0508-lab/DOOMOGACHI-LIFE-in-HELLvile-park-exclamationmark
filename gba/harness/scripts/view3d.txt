# view3d.txt - Options "Combat detail" in the shooter on the game ROM (SP8:

# `make test`). OPT_3D_FAST is option 63 (town.h): 0 Balanced (default),
# 1 Smooth, 2 Max detail.
#   - the row is on the Performance page (OPTPAGE_PERF = 7);
#   - in every mode the game keeps its 30 logic ticks a second

#   - Smooth draws the Vape Cellar at half resolution doubled by r3d_up2:
#     every 2x2 block of the view above the HUD is one colour;
#   - Balanced and Max detail start at full resolution and the governor
#     (r3d.c) drops to half resolution while full-resolution frames would
#     show below 20 / 15 fps, which they do in this fight.
# Floors (expect-fps) are about 85% of what the ROM measured when SP8 landed
# (docs/GBA.md); expect-logic is the 30 Hz game speed less 1.
