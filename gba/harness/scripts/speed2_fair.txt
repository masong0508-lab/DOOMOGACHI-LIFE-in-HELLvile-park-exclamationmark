# speed2_fair.txt - speed tour 2 (SA2, docs/GBA.md "Speed tour 2"): the Fun Fair's seven
# minigames. `make -C gba test-speed2 SPEED2=fair` (fps, work per drawn tick with --worklog,
# the presented frames by vblanks; the table by tools/speed2.py); `make -C gba profile-speed2
# SPEED2=fair` adds a PC profile after every window. tools/speed2.py turns this file into the
# PS1 and Dreamcast scripts (ps1/harness/speed2.sh, dc/harness/speed2.sh).
#
# Window rules (every speed2_*.txt): `seed 1` + a scene command, a short settle, then
# `fps start` .. `wait N` .. `fps GROUP: NAME` (N = 20..130 logic ticks). The table takes the
# frames over 33 / 50 ms from the harness's `gaps` line, and the scene command's own time
# ("command 7/8 ... in N ms": the scene's enter, which runs outside the tick's work) plus the
# first drawn tick as the load freeze.
# Report only: no expect-fps floors yet (the speed wave 2 packages add them).
#
# Each game: its title card (arg 1: Sweet preselected), the autoplay bot on Sweet (arg 49 =
# Sweet | AUTOSTART | AUTOPLAY) and on Hellfire (arg 51: the hellish night version), and
# where the bot gets there inside the window, the results card (core/src/mg.h).
