# creator_speed.txt - the creator's speed on the PS1 (CR9; the GBA's is gba/harness/scripts/
# creator_scroll.txt): the same moves, measured with fps / fpsend (presented frames a second).
# Run by the game's harness target (ps1/CMakeLists.txt). The owner's target is a steady 30
# (DECISIONS "FPS TARGET"); the expect-fps floors are regression gates a little under today's numbers
# (docs/CREATOR.md "Speed": idle 30.1, rows 30.0, a value held 29.9, the species grid scrolled 24.7).
#
#   idle        a new Hillvile citizen on the Species & Body tab, nothing pressed
#   grid scroll RIGHT held in the species grid (each species is tried on)
#   rows        DOWN held through the Outfit tab's rows
#   value step  RIGHT held on the Outfit row the rows scroll stopped on (a new look every few ticks)
