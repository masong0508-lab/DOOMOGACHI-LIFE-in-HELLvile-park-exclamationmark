# boot.txt - the dc/ skeleton (DC2): the ELF or the CDI boots, the core
# starts, the 30 Hz loop runs and the scenes change BOOT -> TITLE.
# For the Flycast harness (dc/harness, DC1); the syntax is the GBA
# harness's (gba/harness/scripts/smoke.txt), and `wait` counts logic ticks
# read from the mailbox (dc_mailbox.ticks), not video frames.
#
# Nothing is drawn yet except the clear colour (2D arrives with DC3), so
# the checks use the mailbox log ring and its scene name. The text probe
# (mailbox commands 11/12, as the GBA's expect-text) is in the game; dcrun
# gets an expect-text command with DC3, when there is text to draw.
# `frames 300` is 5 s of 60 Hz video; the loop runs on the SH4 timer at
# 30 Hz, so the tick count must advance by 150 (+-1) over it (expect-ticks).
# dcrun refuses mailbox commands until the game has written the mailbox
# magic, so `wait 1` (which waits for it) comes before `seed`.
wait 1
seed 1234
expect-log DOOMOGACHI DC: boot ok
expect-log doomo: init
expect-log scene: set BOOT
expect-scene BOOT
shot dc_boot
# the boot splash hands over to TITLE at tick 123 on the native runner
wait 160
expect-log scene: set TITLE
expect-scene TITLE
mark-ticks
frames 300
expect-ticks 149 151
shot dc_title
