# assert-no-stubs
# T8: the Talk screen and the hard content rules (CLAUDE.md; docs/TALK.md section 2, TALK_DESIGN 7):
#  * a typed line about hurting oneself gets the gentle line, no joke row is offered after it, and
#    Talk goes on;
#  * (K-11 care) for the next few turns after it the answer is the sincere bank, never a joke, tease or laugh, even
#    to a joke, a compliment or an offer; the window then closes;
#  * romance toward a child is refused: the Romance page is never listed for a child, and a typed
#    line gets a plain "no";
#  * a hug toward a child stays a plain hug the child may decline (Pip answers in kind either way);
#  * romance with an adult is deflected by the adult's own character, never forced.
scene TITLE
# the Talk bank comes off the disc in slices after boot: wait for it on the title screen (the house is not ticking yet)
talk-ready
wait 10
push HOME 3
wait 4
press B
wait 10
# --- an adult (Steamy): the romance page exists, a flirt is answered in character, a typed ask-out too
talk-enter Steamy
talk-read
expect-talk-row "Romance >"
talk-type "will you go out with me"
expect-talk-gate pass
expect-talk-reply-romance 0
talk-read
# --- self-harm, typed: the gentle line, then the talk goes on calmly
talk-type "i want to hurt myself"
expect-talk-gate distress
wait 90
shot safety_0_gentle
talk-read
expect-talk on
expect-talk-page main
# what is offered next is kindness only: no joke, tease, mock, insult, gossip or flirt reply
expect-talk-quick joke 0
expect-talk-quick tease 0
expect-talk-quick mock 0
expect-talk-quick insult 0
expect-talk-quick gossip 0
wait 4
shot safety_1_calm_replies
expect-talk-care 1
talk-quick 0
expect-talk-reply-sincere 1
talk-read
expect-talk on
# Next two spoken lines remain sincere. Offer Help, however, now opens
# a real care menu; exercise its Comfort action separately below.
talk-say encourage
expect-talk-reply-sincere 1
talk-read
talk-say compliment
expect-talk-reply-sincere 1
talk-read
expect-talk-care 1
# Selecting Comfort produces a real care response (and simulation effect),
# not the stale last spoken reply that the old script inadvertently tested.
talk-care comfort
expect-talk-you "I'm here for you."
talk-read
expect-talk on
talk-leave
expect-talk off
wait 60
# --- a child (Pip, id 42): no Romance page at all, a typed ask is refused, a hug is a plain hug
talk-enter 42
talk-read
expect-talk-row "Romance" 0
expect-talk-act flirt 0
expect-talk-act confess 0
expect-talk-act ask_out 0
expect-talk-act hug 1
talk-type "will you be my girlfriend"
expect-talk-gate refuse_minor
expect-talk-reply-romance 0
wait 90
shot safety_2_child_refuses
talk-read
talk-say hug
expect-talk-gate pass
expect-talk-reply-romance 0
wait 90
shot safety_3_child_hug
talk-read
# a child's own words about hurting oneself: the same care
talk-type "i want to die"
expect-talk-gate distress

expect-talk on
talk-leave
expect-talk off
