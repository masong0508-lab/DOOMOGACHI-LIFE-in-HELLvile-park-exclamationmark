# core/data/parts/spooky/wings_b.txt - spooky batch A3 (CR4): 14 wings on the gene list values 10..23.
# A wing pair is one image-wide script (the painter draws every block once: behind the body from the
# front, over it from the back). Torso anchor, `mirror on`, `scale 255` (about x4): on the figure the torso
# is 10 px half-wide and 6 px half-high, so a written x step is 0.16 px and a y step 0.09 px. Each pair is
# a template `wNN Y` (Y: the vertical offset, 0 on the figure); a smaller scale draws it on the bust.

def w10 X Y
  mat accessory_color light
  shade ball
  solid
  ellipse $X+77 $Y-54 35 45
  solid same
  ellipse $X+100 $Y-11 27 34
  solid same
  mat accessory_color
  shade ball
  decal
  line $X+64 $Y-54 $X+103 $Y-54 1
  line $X+84 $Y-11 $X+116 $Y-11 1
enddef
list wings 10                        # Cherub Mini
block group=1 anchor=torso lod=all view=figure,fighter,chibi
  scale 255
  mirror on
  use w10 0 0
end
block group=1 anchor=torso lod=all view=portrait
  scale 150
  mirror on
  use w10 38 -40
end
