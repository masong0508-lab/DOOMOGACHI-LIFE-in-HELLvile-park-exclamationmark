# core/data/parts/hair/hair_b.txt - hair batch A2 (CR4): 32 hair styles on the gene list values 32..63.
# Hand-authored from the part-script ops; every style is a back block (group 0: what hangs behind
# the head) and a front block (group 4: cap, bangs, top pieces). Hair is hair_color, one ramp, so
# the shape alone tells the styles apart (the shape gate). Coordinates: 256 = one head radius,
# x to the right, y down, `mirror on` doubles a shape to the other side. Chibis get the same blocks.

def hp
  mat hair_color
  shade ball
  solid
enddef
def hpl
  mat hair_color light
  shade ball
  solid
enddef
def hpd
  mat hair_color dark
  shade ball
  solid
enddef
def acc
  mat accessory_color
  shade ball
  solid
enddef
# the hair cap over the top of the head: a dome standing on the hairline Y
def cap Y W H
  mat hair_color
  shade ball
  solid
  crown dome 0 $Y $W $H
enddef
# seen from behind the whole head is hair
def nape
  ifyaw 3,4
    mat hair_color
    shade ball
    solid
    crown dome 0 75 127 127
  endif
  mat hair_color
  shade ball
  solid
enddef
