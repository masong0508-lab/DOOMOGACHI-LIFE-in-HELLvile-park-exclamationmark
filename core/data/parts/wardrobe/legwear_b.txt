# core/data/parts/wardrobe/legwear_b.txt - legwear (CR4 A5), gene list `legwear` values 1..15.
# One leg's frame (portrait_body.c legs): origin the foot, x 256 = the leg's radius (mirrored on the
# left leg), y -256 = the hip, y 0 = the foot. Drawn after the bare leg, under the bottom and the shoes,
# in the legwear colour (the creator's "Legwear col." row). Legs show on the figure, the fighter and
# the chibi, never on the bust, so the blocks skip the bust.

def leg
  mat pattern_color
  shade ball
  solid
enddef
def legl
  mat pattern_color light
  decal
enddef
def legd
  mat pattern_color dark
  decal
enddef

list legwear 1                    # Knee Socks
block group=1 anchor=frame lod=all view=figure,fighter,chibi
  use leg
  capsule 0 -140 0 0 255 255
  use legl
  line -240 -140 240 -140 2
end
