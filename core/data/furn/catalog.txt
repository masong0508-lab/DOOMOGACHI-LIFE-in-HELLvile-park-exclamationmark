# core/data/furn/catalog.txt - the dream house catalog: stats only (owner: H1).
# The art (prims, facings, frames) lives in core/data/furn/art/*.txt (H4);
# core/tools/furngen.c joins the two by key into core/gen/furn_data.c,
# furn_grant.c, furn_iso.c and furn_ids.h (SPEC R19, C3).
#
# IDS ARE THE BLOCK ORDER AND ARE SAVED (9 bits): APPEND ONLY, never reorder
# or delete a block (retire it with `flags2 UNSELLABLE` and price 0 instead).
#
# [key] CATEGORY price "Name (<= 20)"
#   desc "Description (<= 40)"
#   foot W D H       footprint in tiles (1..4) and height in px/4
#   flags F|F        FF_*: WALL RUG SURFACE SMALL LIGHT ANIM HELL BILLBOARD
#   flags2 F|F       PORTAL CURSED NO_SQUASH UNSELLABLE GIFT STARTER
#   fi X             what Live mode does: NONE SIT SLEEP EAT COOK PLAY WATCH
#                    MUSIC READ BATHE PRAY SUMMON EXAMINE TURRET
#   role X           FR_* the rules know it as (BED SEAT TABLE LAMP CANDLE ...)
#   paints A B       default paints (PAINT_* names) or FIXED
#   score c s m      cute, spooky, comfy (-10..10)
#   theme X          THEME_* for Style / Harmony
#   mass N           barricade HP (0 for wall, rug and small pieces)
#   need X           resident STAT_* restored by using it
#   seat N           seat / sleep offset (px)
#   light N          lamp radius (tiles)
#   giver N          resident id of a gift's giver
#   unlock N         unlock id that grants (trophies) or gates it
#   reward Sxxx      the story_final.md mission that awards it
