# core/data/furn/art/pastel.txt - furniture recipes (owner: H4). furngen joins
# each [key] with its catalog.txt row (H1) and bakes the GBA iso facings; the
# PS1 builds the same prims live (HF sec.6.2, 7.1).
#
# Units: x, y in 1/16 tile (a 1x1 piece spans 0..16), z in pixels. Rot 0:
# the piece's front faces +y (screen lower left); its back is at y = 0.
# Wall pieces stand against the y = 0 wall and stay within y 0..3.
#
#   box  x y z  w d h      min corner + size
#   blob x y z  rx ry rz   ellipsoid: centre + radii
#   cyl  x y z  r h        vertical cylinder: centre x y, bottom z, radius, height
#   cone x y z  r h        cone: base centre x y, bottom z, radius, height
#   kind@01 ...            only on animation frames 0 and 1 (`frames N` first)
#
# Materials: A / B (the two paint slots, recolourable), a PAINT_* name
# (fixed; BUBBLEGUM and MINT are reserved for the markers), or ~RAMP (fixed,
# an environment ramp: ~WOOD ~STONE ~STEEL ~BONERAMP ~LAVA ...).
# Styles: soft (dithered fluff), shiny (a highlight), glow (lit from inside).
